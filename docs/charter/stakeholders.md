# Stakeholder map and RACI

**Decision:** The ClaimSense co-pilot is rolled out to the motor claims team  
**Accountable:** Head of Claims

| Stakeholder | Role | RACI | Brief role | Veto | Wants | How we lose them |
|---|---|---|---|---|---|---|
| Head of Claims | Executive sponsor | A | approver | hard | first pass in minutes; consistent, defensible decisions | a demo with no numbers; slipping the five-week timeline |
| Claims QA Lead / Senior Adjuster | Reviews co-pilot output | R/C | reviewer | quiet | reasoning she can audit; citations she can check | uncited or confidently wrong verdicts |
| Licensed motor adjusters *(off org chart)* | Daily users, confirm every outcome | R | daily_user, blocker | quiet | less file-gathering; stay accountable, not replaced | a tool that adds clicks or feels like it decides for them |
| CISO / Information Security | Data and access gate | C | blocker | hard | no PII, enforced access control, full audit trail | access control written as a prompt |
| Compliance / Claims Regulatory | Fair-claims-handling obligations | C | blocker | hard | a human decides; reasoning is recorded | anything that looks like an auto-decision |
| SIU Lead | Special Investigations Unit | C | - | none | fewer false referrals; better-evidenced true ones | flooding SIU with low-quality referrals |
| Claims / Policy IT owner | Owns the three systems | C/I | - | bandwidth | no load on legacy systems; no write surprises | needing system changes before value is shown |

**Required roles (brief):** approver: Head of Claims; blocker: Licensed motor adjusters, CISO / Information Security, Compliance / Claims Regulatory; daily_user: Licensed motor adjusters; reviewer: Claims QA Lead / Senior Adjuster
